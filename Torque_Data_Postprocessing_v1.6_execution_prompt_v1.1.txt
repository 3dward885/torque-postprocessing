3. DEFINE A SEPARATE GROSS FIELD-CHANGE CHECK

Add a concise acquisition policy with clear labels such as:

Field condition:
  Fixed field
  Changing field permitted

For fixed-field experiments:
  Maximum field change within a scan (T): [value]

New work defaults to Fixed field. Legitimate changing-field measurements remain supported through an explicit recorded choice.

Keep these concepts separate:
- Measured within-sweep field variation.
- Deviation from an assigned field setpoint.
- Existing nominal-coordinate rounding.
- The existing stable-field tolerance of 1 Oe.

The gross-change check must use ORIGINAL MEASURED field values, converted with the declared Oe-to-T convention, before nominal rounding, angle-range filtering, fitting or centering.

For each complete acquired scan:
  field_span_T = max(B_measured_T) − min(B_measured_T)

Use Decimal arithmetic and a documented inclusive boundary:
  field_span_T <= configured_limit_T passes this check.
  field_span_T > configured_limit_T requires review.

Do not make the check depend on the plotting window or silently split one acquisition into smaller passing segments.

Threshold authorization:
- The user has NOT specified a universal numerical limit.
- “A massive change, such as 1.5 to 1 T” is an example, not an exact cutoff.
- Do not hardcode 0.5 T: this measured event is slightly smaller than 0.5 T and would pass a literal 0.5 T limit.
- Do not invent an accepted experimental threshold or substitute the existing 1 Oe tolerance.
- Provide an editable per-file limit, saved with units and provenance.
- Blank means not configured, not unlimited.
- When execution begins, ask one concise question for the intended experimental limit while continuing independent implementation and tests.
- Use clearly labelled synthetic limits in software tests until an experimental value is supplied. An unanswered question is not approval.

P003’s recorded large change and the experiment’s fixed-field intent are already established. Do not ask the user to reconfirm those facts. Distinguish those facts from a saved decision to exclude a particular acquisition.
