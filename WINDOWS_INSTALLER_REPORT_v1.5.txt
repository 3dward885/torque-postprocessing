DESIGN
output_controls.py owns the compact draft/committed sample controls and paired
filename dialog. output_settings.py validates the separate source-hash-bound
version-1 output block and reuses the existing normalization/token arithmetic.
Scientific configuration stays version 1.2; baseline schema stays version 2.
Only corrected preview uses chosen molar units. Raw/background/stages and the
manual torque-zero editor remain N m.
Molar DATs are generated from serialized N m torque, using the existing 50-digit
Decimal factor and exact product. No refit, recenter or accumulated conversion.
Save plots writes JPEGs/details only. The ordinary DAT details folder records
both data outputs, normalization and replay settings.
Data publication reuses bounded Windows access/sharing-lock retries and safe
rollback. Collisions never overwrite existing files.
