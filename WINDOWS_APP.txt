Torque Data Postprocessing 1.6 - Windows application

INSTALL
Double-click Torque_Data_Postprocessing_1.6_Setup_x64.exe and follow Setup.
Open Torque Data Postprocessing from the Start menu. A desktop shortcut is optional.
Python, Tk and the required numerical/plotting libraries are included.
Installation and processing require no network connection or Python setup.
The installer is not digitally signed with a publisher certificate.

USE
Open data -> Subtract background -> optional Center zero -> Save treated data.
Use Acquisition settings for your experimental temperatures and tolerances.
Use Angle range before processing to exclude unwanted endpoint measurements.
Help > User guide, or F1, opens the local instructions and examples.
Source files and existing output files are never overwritten by processing.

OUTPUT
Choose Torque (N m), or Molar torque (N m/mol), in the main Output section.
Molar mode needs Sample mass (mg) plus Molar mass (g/mol), or Amount (mol).
Molar mass alone is insufficient: n = mass_mg/(1000*molar_mass_g_mol).
Check the calculated amount and Apply. Cancel discards drafts. Each file has
its own quantities; no values are inferred or copied from another sample.
Save both data files shows the ordinary and molar filenames before writing.
Save plots produces grouped white Arial JPEGs (2400 x 1800, 300 dpi), with
experimental markers only. Plot saving writes no DAT. Corrected preview uses
the chosen units; raw/background/stages and Center zero remain in N m.
Save settings preserves output choices; a molar session replays both DATs.
Old sessions default to Torque. Keep the .dat.details and plots.details folders.
Existing outputs are never overwritten. Position correction is still deferred.

FILES
Default installation: %LOCALAPPDATA%\Programs\Torque Data Postprocessing
Startup logs/cache: %LOCALAPPDATA%\Torque Data Postprocessing
Treated data and its .dat.details folder go to your chosen Save As location.
Keep saved data outside the installation directory.
Uninstall through Windows Settings > Apps. Saved data is not removed.
Install an update with the same Setup destination after closing the application
yourself. Setup does not close running programs. A locked-file update stops
without replacing the existing installation. Logs/cache remain after uninstall;
you may remove that app-specific user-data folder manually if no longer needed.

PORTABLE COPY
Alternatively extract the portable ZIP and run Torque Data Postprocessing.exe.
Keep it together with TorqueDataCLI.exe and the entire _internal folder.
Moving only the EXE will not work. No setup scripts are needed.
Use a short installation/extraction location. Setup rejects paths that exceed
the bundled Windows libraries' path-length limit; the default location is suitable.

HEADLESS REPLAY (PowerShell)
& "$env:LOCALAPPDATA\Programs\Torque Data Postprocessing\TorqueDataCLI.exe" process --session "C:\path\settings.json" --dat "C:\path\treated.dat"
Use a new output filename. The command has the same options as cli.py.
Settings contain raw-file paths; move/update those paths when relocating data.
Accepted zero adjustments still validate source, numerical settings and runtime.
A different Windows/Python/NumPy environment can require reviewing and applying
an old adjustment again. These checks have not been disabled for packaging.

Windows 64-bit build. See WINDOWS_INSTALLER_REPORT_v1.6.txt in the source project
for the actual validation and limits. No automatic updating or telemetry added.

FIELD REVIEW (v1.6)
New and migrated sessions require an explicit field policy. For Fixed field, enter your review limit in T in Acquisition settings. No experimental default is supplied.
The full acquired measured field span is rounded to 0.01 T (nearest; ties away from zero). At or above the limit requires review. This does not alter field measurements or nominal coordinates.
Review scan shows original rows and the field trace. Detection never excludes. Enter a reason and explicitly exclude the entire scan or permit an intended changing-field acquisition. Closing review leaves it unresolved. All final exports are blocked while an included scan is unresolved. Raw snapshots and the row ledger retain excluded measurements.
Save a new session for CLI replay. Old monotonic parsing does not constitute changing-field permission. Changing the source, scan identity or field policy invalidates affected decisions; display and molar settings do not.
