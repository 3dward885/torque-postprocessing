1. Back up the GitHub checkout and inspect its uncommitted changes.
2. Extract Torque_Data_Postprocessing_v1.5_source_update.zip.
3. Copy its project files into the GitHub checkout, preserving subfolders and
   reviewing replacements. Close any source-based application yourself first.
4. Review the diff, commit and push manually.

output_controls.py, Help, tests and Windows build files. No removals are required.

runs into the source commit. Keep the installer/portable runtime ZIP separate.
