2. ESTABLISHED PIPELINE AND LIMITS

Verified reconstruction:
Dataset                 Signal passes  Signal rows  Centering result
Previous Rot1           23             943          15 mean, 8 midrange; choices reference-selected
Previous Rot2           20             820          Fixed midrange, all exact
New Ho2thd4Pc Rot1       20             818          Fixed midrange, all exact

Midrange therefore reproduces 71 of the 86 tested passes. This supports it as the application default for this recipe, not as a universal physical rule. The previous Rot1 selector remains unresolved. Its diagnostic choice table must not become an automatic production rule.

For each signal angular pass, with its selected own-rotation, same-temperature background:

  r6_i = Q6(raw signal torque token_i)
  z6_j = Q6(raw background torque token_j)
  p(theta) = unweighted degree-six least-squares polynomial fitted to
             z6_j versus NOMINAL background angle_j
  b_i = p(nominal signal angle_i)
  u_i = r6_i - b_i

  Midrange: c = (max(u) + min(u)) / 2
  Mean:     c = arithmetic mean(u)

  D_internal_i = u_i - c
  D_export_i = Q8(D_internal_i)
  E_export_i = Decimal(D_export_i) * Decimal(k), when molar output is enabled

Implementation requirements:
- Preserve the verified input quantization semantics: six SIGNIFICANT decimal digits from original tokens, nearest rounding, not six decimal places or truncation.
- Use the same scaled polynomial domain [0,200] degrees mapped to [-1,1] and stable NumPy least-squares implementation as the verified code.
- Keep input point order and fitting/evaluation arithmetic consistent enough to preserve exact reference export values. Do not replace the numerical method casually during refactoring.
- Fit coefficients only from actual raw background samples. Coefficients are fitted parameters; degree, coordinates, precision stages and operation order are fixed recipe settings.
- No extra intermediate rounding is present in the verified recipe. D uses the verified eight-significant-digit binary64 export formatting; E multiplies that exported decimal value exactly.
- No signal smoothing, averaging, regridding, angle shift, amplitude normalization, enforced periodicity, invented data, reference-derived background, or free fitted baseline offset.
- Do not reapply an assumed calibration. Status meanings and uncertainty weighting remain undocumented; do not filter or weight by them.
- An offset varying between passes is not evidence of instrumental drift. Centered output cannot uniquely identify an absolute background constant or historical operation order.

Do not expose an unrestricted model-search interface. Keep this validated recipe fixed in normal use. An optional “no centering” diagnostic view may be provided, clearly outside the default reference treatment.

Support these input schemas initially:

   positions; right-pad only genuinely omitted trailing fields.
   Primary 1-based fields:
     4 Temperature (K)

   Std. Dev. 14 as metadata. Do not substitute them for the primary variables.
   Support documented populated trailing fields without shifting positions.

   Do not infer a timestamp column from that line. Reject unexplained malformed
